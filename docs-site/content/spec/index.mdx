# 交接

**本页回答**：现在有什么活在路上、做到哪儿了、交给下一个会话要看什么。

这一区的规矩一句话：**有页 = 有活在路上，做完删**。一件活一页，页头是验收清单，正文是实施方案；
随做随提交，做完把结论拆解归梁——现状进 [现状区](/docs)、决定落一张 [轨迹卡](/trajectory)、
没做的回 [未来区](/future/overview)——然后把这一页删掉。这一页本身是导读，不算活。

一页的骨架：

```text
---
title: <一句话说清这件活>
description: <验收标准，一行>
---

## 验收
- [ ] 条目一（能被机器或人当场验的）
- [ ] 条目二

## 方案
散文。改哪几处、顺序、门禁怎么跑。指回总方案（如果有）。

## 进度
一行一次提交或一次会话，新的在上。
```
