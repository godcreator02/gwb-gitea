# 系统地图

**本页回答**：`gwb-gitea` 拆成哪几块、各住哪、块与块之间谁依赖谁、新来的人先读哪块。

## 模块

一行一块。「在哪」钉目录树，「先读」指向那一块的页：

| 模块 | 在哪 | 管什么 | 先读 |
| --- | --- | --- | --- |
| （待填） | `src/` | | |

## 依赖方向

单向。谁能 import 谁一句话说清，反向的一律不许——写成一条能被代码推翻的论断，再钉住守它的那处
（边界测试、package.json 的 dependencies、入口文件的 import 表都行）。

## 每块一页

每个模块在这一区有自己的一页，固定块按这个顺序：

管什么 / 不知道什么 / 数据结构（只钉形状，不列字段）/ 提供的接口 / 依赖的接口 / 怎么单独测 /
代码地图（在哪、先读、读序、可跳过）。

钉目录树的写法（写在正文里、单起一行，不是写在围栏里）：

```text
@@docfirst tree ../src depth=2 @@
```
