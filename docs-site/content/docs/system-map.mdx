# 系统地图

**本页回答**：`gwb-gitea` 拆成哪几块、各在哪、块与块之间谁依赖谁、新来的人先读哪块。

@@docfirst tree ../src depth=1 @@

| 模块 | 在哪 | 管什么 | 先读 |
| --- | --- | --- | --- |
| 插件入口 | `src/index.ts` | 登记设置项、说明书与 `gitea.http`；handler 里读设置、发请求 | [依赖的服务与说明书](/docs/plugin) |
| 纯逻辑 | `src/core.ts` | 参数收窄、URL 组装、回执整理、脱敏，不碰网络与设置 | `tests/core.test.ts` |
| 小工具 | `src/vocab.ts` | `isRecord` 这类无状态小函数 | — |

## 依赖方向

`index.ts` 引 `core.ts`，`core.ts` 只引 `vocab.ts`，反过来不引：

@@docfirst ref ../src/core.ts:1-1 @@

所以 `core.ts` 不启动工作台也能测，真发请求只发生在 `index.ts` 的 handler 里。
