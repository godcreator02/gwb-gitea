# 挂上去的面

**本页回答**：`gwb-gitea` 挂在工作台的哪几个面上、各是硬依赖还是局部注入、说明书从哪儿进收集器。

## 依赖

| 面 | 怎么拿 | 缺了会怎样 |
| --- | --- | --- |
| 命令总线 `gwbCommands` | `export const inject` | **挂不上**——inject 是等待机制，不是建议 |
| 设置 `gwbSettings` | 同上 | 同上 |
| 说明书 `gwbSkills` | `ctx.inject([...], fn)` 局部注入 | 照常挂：命令照旧，只是 `skill.list` 里没这一份 |
