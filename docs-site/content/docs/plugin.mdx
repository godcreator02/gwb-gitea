## 依赖

| 服务 | 怎么拿 | 缺了会怎样 |
| --- | --- | --- |
| 命令总线 `gwbCommands` | `export const inject` | **不加载**——inject 是等待机制，不是建议 |
| 设置 `gwbSettings` | 同上 | 同上 |
| 说明书 `gwbSkills` | `ctx.inject([...], fn)` 局部注入 | 照常加载：命令照旧，只是 `skill.list` 里没这一份 |

## 说明书怎么随包发布
