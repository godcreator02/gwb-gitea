# 孵化

**本页回答**：这个仓里有哪些手动重复过两次以上的操作，值不值得做成命令、skill 或脚本。

一条一节：`## <日期> <标题>`，下面一段写做了什么、重复了几次、做成什么形态合适。
做成了就删掉这一条（决定落轨迹卡）；半年没动的也删。这一页仓内直接编辑，不经 MCP。
